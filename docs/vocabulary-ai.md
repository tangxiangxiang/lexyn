# AI 词汇增强

词汇释义生成复用 Settings 中保存的 MiniMax API 密钥。密钥加密保存在服务器数据库，文本请求由服务端发送；浏览器不直接接触密钥。首次生成会验证文本 API 权限并使用账户文本额度。请核对 [MiniMax 中国区计费说明](https://platform.minimax.cn/docs/pricing/overview)。

## 生成与迭代

- 新词先写入服务器 SQLite，再异步开始释义生成。词条保存不依赖 AI 成功；生成失败时，词条和用户已经输入的释义仍然保留，可在编辑器重试或主动优化。
- 只在新增词条、用户主动优化或启动批量任务时调用 AI。打开 Library、Learn、Review 不会触发生成。已优化的词条不会因重复自动请求再次扣费。
- ECDICT 是不可变参考。安装后，MiniMax 请求会收到当前词条匹配的 ECDICT 原始 `translation`、`definition`、`pos`、`phonetic` 与词典版本；没有本地匹配时，仅根据单词和用户提供的语境生成。查询或生成都不会修改 ECDICT 数据库。
- 再次优化以调用开始时最新保存的释义和音标为主要输入，以 ECDICT 原文为辅助参考。AI 可纠错、整理和补充义项，并更新有把握的读音。单侧返回空值时保留该侧已保存的音标。
- 每次编辑都会递增 Entry revision。AI 返回时若 revision、词条拼写或所在词本已变化，服务端会拒绝旧结果，避免较早的响应覆盖后续人工修改。用户保存 B 后再次点「用 AI 优化」，下一次请求会以 B 为基础继续生成。
- CSV 覆盖同一单词的非空释义会保存为最新的人工版本；同词 ECDICT 快照保留。下次 AI 优化读取这份 CSV 释义作为主要输入。未映射或空白释义不清空旧内容，原样导入的重复释义也不降级已有结构化释义。

## 结构化结果

MiniMax-M3.1-Flash 在同一次请求中返回词性分组、完整中文义项、可选专业领域、英美 IPA 和各自的检查状态。提示词优先使用自然的中文词语、短语和通行译名，保留常见词性、普通与专业义项，以及区分义项所需的细节。服务器校验 JSON、词性格式、领域标签、中文义项、重复项、占位文本和截断状态。IPA 两侧独立校验。

最终结构保存在 `Entry.dictionaryMeaning`，`Entry.meaning` 由同一结构生成完整文本投影，供 Review 查询及旧调用点读取。原始 ECDICT 快照保存在 `Entry.dictionaryReference`，不会与最终释义混成一个字段。Library、Learn 和 Review 只呈现最终完整释义；Review 正面显示全部中文义项，揭晓后再显示英文。

模型独立生成英式和美式 IPA。某侧缺失时保留该侧已有音标。两侧均缺失、没有已保存音标且词条未被手动清空时，使用 ECDICT 通用音标回退。手动清空的词条在用户重新录入音标前保持空白。格式校验检查字符、分隔符和长度，读音准确性仍需人工核对。AI 标记的不确定读音和未通过格式检查的音标会单独保存为 `phoneticsNeedsReview`，可通过词库的「建议检查」筛选找到。

## 批量补全

词本的「缺少释义」筛选可启动服务器端批量任务。每个目标都经过 MiniMax，ECDICT 只作为输入参考，不会直接被当作生成成功。任务最多处理 1,000 个活动词条，模型请求每组最多 3 个词，服务器最多并发 2 个文本请求、每分钟 12 次，并同时只运行一个批量任务。

任务状态和进度保存在 SQLite，页面刷新后可继续查看或取消后续处理。每一批写入前会验证词条 revision、删除状态和词本状态；冲突、无效输出和失败不会覆盖现有释义。任务记录保留 24 小时。

词本的「AI 补全英美音标」针对已有释义但缺少任一侧音标的词条。该任务写入缺失的口音、符合条件的通用回退和音标检查状态。任务保留已有释义、音标和复习排期，跳过已有双音标或手动清空音标的词条。

## 备份

JSON v5 包含结构化最终释义、完整 `meaning` 投影、音标、必要的 ECDICT 快照、词条修订号及学习与复习历史。v4 备份仍可恢复；完整恢复由服务端 CLI 再次校验。SQLite 在线备份包含服务端业务数据，但不包含独立的 `dictionaries/ecdict.sqlite` 文件。安装和更新词典请参阅 [ECDICT 安装文档](dictionary.md)。
