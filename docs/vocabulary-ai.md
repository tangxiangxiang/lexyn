# AI 词汇增强

在设置的发音区保存 MiniMax API 密钥。AI 词汇增强复用同一份加密凭据，设置会分别显示文本访问状态。首次生成前文本权限尚未验证，生成会使用账户的文本额度。请核对 [MiniMax 中国区计费说明](https://platform.minimax.cn/docs/pricing/overview)。

- 在新增或编辑词条时输入词汇，可补充语境提示。点击 AI 补全或重新生成后，结果直接填入尚未改动的字段。继续编辑，最后用原有 Save 操作保存。保存已有词条仍需匹配当前版本。
- 在词本的「缺少释义」筛选中确认一次，服务器从整个词本处理最多 1,000 个缺少释义的活动词条，每次模型请求最多 5 个。任务限时一小时，可以刷新查看进度或停止后续生成。已保存的结果会保留。重启后中断的任务可从剩余缺失词条重新开始。
- 服务器每组自动保存时会重新检查词条版本和可编辑状态，保留已有释义、解释和例句。词义存在明显歧义时，有效结果也会保存并加上「建议检查」标记。可在词本筛选查看，手动修改释义会清除标记。

文本请求走 [MiniMax 中国区 OpenAI 兼容 Chat Completions](https://platform.minimax.cn/docs/api-reference/text-chat-openai)，使用 `MiniMax-M3.1-Flash` 非流式生成。模型返回 JSON，服务器校验词条映射及字段。词汇、词本名、描述和可选提示会随生成请求发送给 MiniMax。服务器最多并发 2 个文本请求、每分钟 12 次，同一时刻仅运行一个批量任务。

已保存的简短释义、补充解释、例句、释义来源与建议检查标记进入词库 JSON v4。批量任务进度独立保存在 SQLite，最后一份任务记录可查看 24 小时。词库 JSON 不包含任务和凭据。
